DIALOG / ОБСУЖДЕНИЕ МАКЕТА

Аналитическая презентация

Прежний макет и отдельное предложение для обсуждения. Данные синтетические; кнопки запускают только демонстрационные переходы.
Ограничения СберЧата · message.text 4096 / title 128 / description 256 · UTF-16

30 групп — подтверждённый предел. Граница 30 кнопок в группе предварительная. Лимиты считаются после подстановки демонстрационных данных. При превышении показывается предупреждение, текст не обрезается.

Markdown поддерживается в верхнем message.text. Title и description — обычный текст без Markdown и ручных переносов. `verticalLayout` сохраняется в структуре, но геометрию предпросмотра не меняет.

Включи «Пощёлкать сценарий», чтобы пройти демонстрационные переходы.
