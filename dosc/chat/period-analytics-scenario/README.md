# Мастерская макета аналитической презентации

Интерактивная мастерская сохраняет исходный сценарий аналитической презентации и предоставляет отдельный вариант для обсуждения.

## Запуск

Из этой папки выполните в PowerShell:

```powershell
node .\server.mjs
```

Откройте адрес, напечатанный сервером (по умолчанию `http://127.0.0.1:28766/`). Если порт занят, задайте другой перед запуском:

```powershell
$env:PERIOD_ANALYTICS_PORT = '28767'
node .\server.mjs
```

Сервер локально отдаёт HTML, CSS и ES-модули, а также формирует PPTX по запросу макета. Внешние сервисы и реальные клиентские обращения не подключены. В Node.js может появиться предупреждение об экспериментальном `localStorage`; оно относится к среде запуска сервера, а черновик сохраняется в браузере.

## Сценарии и экраны

Сохранены приветствие и сведения о продуктах, развилка «Аналитика за период» / «Сгенерировать презентацию», единый этап настроек, отдельное сообщение с переходом к ранее созданным презентациям, подготовка, готовый файл и запасное состояние с примером. «Аналитика за период» остаётся инертной кнопкой, как в исходном макете. Кнопка «Сгенерировать презентацию» сразу открывает настройки. Каждый список оформлен отдельной группой с поясняющим описанием в порядке: продукт, детализация периода, тип диаграммы, детализация по тематикам. Кнопки «Сгенерировать презентацию» и «Назад» стоят вместе в отдельной группе именно в таком порядке; над «Назад» — разделительная линия. История доступна после настроек; возврат из истории ведёт к ним с сохранённым выбором.

В истории показывается до пяти записей на страницу с продуктом, периодом, датой и статусом; переходы по страницам работают для любого числа записей. Синтетические примеры дают несколько страниц для проверки пагинации. Повторное скачивание и генерация файла выполняются локально.

## Мастерская

- «Как сейчас» — неизменённое содержимое прежнего макета аналитической презентации.
- «Предложение» — редактируемый режим, открывается по умолчанию.
- «Рядом» — сравнение исходника и предложения.
- Переключатель экранов показывает состояния сценария. «Пощёлкать сценарий» включает локальные кнопки переходов.
- Редактируются message.text, заголовки, описания, подписи и варианты списков. Порядок групп и действий меняется перетаскиванием и кнопками «Выше» / «Ниже».
- Комментарии сохраняются отдельно для каждого экрана. Доступны отмена последнего изменения и восстановление выбранного экрана.
- Черновик хранится в отдельном ключе `period-analytics-workbench-v1`. Ключ истории презентаций сохраняет прежнее имя `period-analytics-presentation-history-v1`.
- Экран настроек отображает два последовательных сообщения СберЧата: параметры презентации и отдельное сообщение с переходом к истории. Предпросмотр, сравнение и JSON показывают обе структуры в том же порядке.
- JSON экспортирует и импортирует тексты, порядок, `verticalLayout`, шаблоны и комментарии. Доступны текстовое представление, копирование и JSON структур сообщений.
- Черновик прежней версии перед миграцией автоматически копируется под ключ с суффиксом `before-revision-*`; прежние шаги выбора презентации и продукта переносятся в новый поток без потери пользовательских подписей и комментариев. При каждом изменении структуры обновляется версия схемы черновика.
- Счётчики используют UTF-16 после подстановки демонстрационных значений. Переполнение отмечается предупреждением, текст полностью сохраняется. Предел 30 кнопок в группе помечен как предварительный.
- Режим предпросмотра шириной 390 px и редактор на отдельной панели доступны через настройки просмотра.

## Проверки

Примеры презентаций с легендой круговой диаграммы и обновлённым отступом строки итога: [месячный отчёт](examples/analytics-synthetic-sample.pptx) и [недельный отчёт](examples/analytics-weekly-synthetic-sample.pptx). В легенде показываются цвет, тематика, число обращений и доля; именно эти файлы использует резервная выдача макета.

Предыдущий полный прогон модели черновика, экранных данных, переходов и синтетических отчётов прошёл 41 тест. Генератор проверен `node --check`; тесты раскладки покрывают легенду, ось Y, подписи линейного ряда, плотность подписей для дневной детализации и синюю палитру. Если детализация тем отключена, линейная диаграмма подписывает значения над точками ряда; при дневной детализации подписи расставляются с шагом для сохранения читаемости.

Проверить мастерскую в браузере и сохранить требуемые снимки в этой среде не удалось: браузер Codex получил `ERR_CONNECTION_TIMED_OUT` для локального сервера, а команда `curl` из среды исполнения также не смогла подключиться к loopback-порту. Сервер при этом сообщил, что порт 28766 уже занят, поэтому для ручного запуска можно выбрать свободный порт через `PERIOD_ANALYTICS_PORT`. После открытия макета следует проверить состояния, адаптивность, импорт/экспорт и скачивание PPTX; визуальные снимки пока не приложены.
