# JasperReports: шаблоны аналитической презентации

Целевой формат — JRXML для JasperReports Library 6.18.1. Каждый из четырёх файлов формирует две страницы: «Жалобы» и «Консультации». Разница только в нижней диаграмме. Шаблоны и customizer также проверены на JasperReports 6.21.3.

| Шаблон | Нижняя диаграмма |
| --- | --- |
| bar-aggregated.jrxml | Столбчатая диаграмма, одна серия «Все обращения» |
| bar-by-topic.jrxml | Накопленная столбчатая диаграмма, серии по тематикам |
| line-aggregated.jrxml | Линейная диаграмма, одна серия |
| line-by-topic.jrxml | Линейная диаграмма, серии по тематикам |

Все варианты содержат круговую диаграмму с легендой за последний полный месяц, итог, топ-3 подтематик и меры. Цвета — синие; легенда нижней линейной диаграммы скрыта; числовые деления Y отображаются.

## Входные DTO

Главный источник — JRBeanCollectionDataSource с двумя JavaBean-объектами ReportSlide в порядке жалобы (kind=toxic), консультации (kind=consultation). Группа kind начинает новую страницу. Нужны свойства:
- kind:String; slideTitle:String; productName:String;
- productPeriodCaption:String; lastMonthTotalText:String; reportPeriodText:String;
- periodTypeLabel:String (Месяц, Неделя или День); pageLabel:String;
- pieSlices:Collection<PieSlice>; trendPoints:Collection<TrendPoint>;
- topSubtopics:Collection<TopSubtopic>.

PieSlice содержит topicName:String, count:Long, shareLabel:String (например, 32%). TrendPoint содержит periodOrder:Integer, periodLabel:String, seriesName:String, value:Long, periodTotal:Long. Передавайте точки в порядке возрастания periodOrder, сначала период, затем тема. Подпись периода уже отформатирована (например, «сен», «06–12 сен», «01»). Шаблон не вычисляет даты и не ограничивает число категорий.
- Месяц: январь — последний полный месяц текущего года.
- Неделя: 13 полных недель до последнего полного воскресенья.
- День: каждый день последнего полного месяца.
- Для агрегированных вариантов одна серия «Все обращения». Для разбивки имя серии — тематика. periodTotal для каждого периода равен сумме тематических серий.
- pieSlices всегда содержит значения за последний полный месяц.

TopSubtopic содержит rank:Integer, text:String, count:Long, sharePercent:Integer, measure:String. Передавайте ровно 3 записи по убыванию веса.

Экспорт: JasperCompileManager.compileReport → JasperFillManager.fillReport с JRBeanCollectionDataSource → JRPptxExporter. Класс src/ru/sberbank/avatar/reports/AnalyticsChartCustomizer.java должен быть скомпилирован и доступен JasperReports в classpath: он применяет синюю палитру, подписи итогов над накопленными столбцами, подписи агрегированной линейной серии (для дневных графиков — около 10 равномерных меток) и поворачивает подписи X при числе точек свыше 16. Порядок тематик должен быть одинаковым в pieSlices и trendPoints.

Файл synthetic-data.json содержит синтетические двухстраничные примеры для месяца (9 точек), недели (13 точек) и дня (30 точек); в каждом периоде есть агрегированный и тематический ряды. Для заполнения шаблона выбирайте trendPointsAggregate или trendPointsByTopic в зависимости от шаблона. Все значения вымышлены.

DTO/SQL в проект не добавлялись: контракт реального источника обращений неизвестен. Четыре JRXML скомпилированы JasperReports 6.18.1 и 6.21.3; customizer скомпилирован и запущен на круговой, накопленной столбчатой, столбчатой и линейной диаграммах обеих версий. В 6.18.1 используется JFreeChart 1.0.19, в 6.21.3 — JFreeChart 1.5.3; различия API customizer обрабатывает через совместимые вызовы.

Экспорт в PPTX проверен на JasperReports 6.18.1: каждый шаблон заполнен двумя синтетическими страницами («Жалобы» и «Консультации»), экспортирован через JRPptxExporter и дал корректный ZIP-пакет PPTX с двумя `ppt/slides/slide*.xml`. Для агрегированных шаблонов передана одна серия «Все обращения», для тематического столбчатого — несколько серий на одну категорию периода; визуальная проверка подтверждает стек тематик в одном столбце. Подписи сумм над столбцами и значений над точками линейного графика отображаются, в том числе для последнего периода. Примеры результата сохранены в `output/pptx-verify/reports`.
